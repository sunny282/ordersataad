Manage Statuses

This fixed sequence — not the sheet's dropdown — controls what technicians can select. From any status, a technician can only move to the next one here, or flag Problematic, or keep the current status. Reorder with the arrows; add a new fixed status below. Auto-approve and View-only apply only to technicians — coordinators and admins can always pick any status directly.
